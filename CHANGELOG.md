# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] - 2026-10-26

### Added

- Automatic opening of `examples` workspace folder when running `make run-vscode-with-extension-only`.

### Changed

- At Linux, replaced `.zip` release package with `.deb`. It detects system-installed `gingaf` executables and informs and suggests to run `apt install` on downloaded `.deb` packages.

## [0.2.0]

### Added

- Download the latest version of `gingaf` executable from [GitHub releases](https://github.com/ginga-org-br/gingaf/releases/).

## [0.1.1]  

### Added

- Support launching `gingaf` executable by downloading release [v0.1.1](https://github.com/ginga-org-br/gingaf/releases/tag/v0.1.1) from GitHub.
